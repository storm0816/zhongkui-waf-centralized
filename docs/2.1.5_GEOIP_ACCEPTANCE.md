# ZhongKui WAF 2.1.5 验收操作文档

本文用于验证 2.1.5 的程序发布基线和 GeoIP 发布中心。测试环境：

- Master：`10.15.108.11`
- Node：`10.15.108.69`
- 项目目录：`/opt/openresty/zhongkui-waf`
- GeoIP 文件：`/opt/openresty/share/GeoIP/GeoLite2-City.mmdb`

> 所有命令均在对应服务器执行。需要修改系统文件的命令请使用 `root`，或在命令前加 `sudo`。

## 一、升级前基础检查

### 1. Master 检查

登录 `10.15.108.11` 后执行：

```bash
cd /opt/openresty/zhongkui-waf
grep APP_VERSION lib/constants.lua
/opt/openresty/nginx/sbin/nginx -t
sha256sum /opt/openresty/share/GeoIP/GeoLite2-City.mmdb
mmdblookup --file /opt/openresty/share/GeoIP/GeoLite2-City.mmdb \
  --ip 8.8.8.8 country iso_code
```

预期结果：

- 程序版本为 `2.1.5`。
- Nginx 显示配置检查成功。
- SHA-256 输出 64 位校验值。
- `mmdblookup` 能返回国家代码，不能报文件损坏。

### 2. Node 检查

登录 `10.15.108.69` 后执行：

```bash
cd /opt/openresty/zhongkui-waf
grep APP_VERSION lib/constants.lua
/opt/openresty/nginx/sbin/nginx -t
systemctl is-enabled zhongkui-node-updater.timer
systemctl is-active zhongkui-node-updater.timer
systemctl cat zhongkui-node-updater.service | grep ExecStart
sha256sum /opt/openresty/share/GeoIP/GeoLite2-City.mmdb
```

预期结果：

- 程序版本为 `2.1.5`。
- 定时器结果分别为 `enabled`、`active`。
- `ExecStart` 同时包含 `node_updater.sh` 和 `geoip_updater.sh`。

## 二、创建 2.1.5 程序快照

1. 浏览器打开 `http://10.15.108.11:1226`。
2. 进入“集群与大屏 -> 发布中心”。
3. 点击“创建程序版本”。
4. 说明填写：`2.1.5 GeoIP 发布中心基线`。
5. 创建后确认“程序版本”页出现 `2.1.5`。

在 Master 上校验快照：

```bash
cd /opt/openresty/zhongkui-program-releases/2.1.5
sha256sum manifest.txt
cat manifest.sha256
wc -l manifest.txt
grep -E 'geoip_(update|release)|geoip_updater|geoip_release' manifest.txt
```

预期结果：

- `manifest.txt` 的实际 SHA-256 与 `manifest.sha256` 一致。
- 清单中包含 GeoIP 发布中心后端和 Node 更新脚本。

> 版本快照不可覆盖。若页面提示 `2.1.5` 已存在，说明已经创建，不要删除后重建。

## 三、创建当前 GeoIP 基线

1. 在发布中心点击“创建 GeoIP 版本”。
2. 说明填写：`2.1.5 GeoIP 基线数据`。
3. 进入“GeoIP 数据”页，记录生成的数据版本和 SHA-256。

在 Master 上查看版本目录：

```bash
ls -lah /opt/openresty/zhongkui-geoip-releases/
find /opt/openresty/zhongkui-geoip-releases -maxdepth 2 -type f -print
```

将页面中的数据版本替换到以下命令：

```bash
GEOIP_VERSION='页面显示的数据版本'
cd "/opt/openresty/zhongkui-geoip-releases/$GEOIP_VERSION"
sha256sum -c SHA256SUMS
mmdblookup --file GeoLite2-City.mmdb --ip 8.8.8.8 country iso_code
```

预期结果：

- `sha256sum` 显示 `GeoLite2-City.mmdb: OK`。
- 固定 IP 查询成功。

## 四、发布新 GeoIP 数据

### 1. 准备新 MMDB

先将待发布文件上传到 Master 的 `/tmp/GeoLite2-City.mmdb.new`，然后执行：

```bash
NEW_MMDB=/tmp/GeoLite2-City.mmdb.new
ACTIVE_MMDB=/opt/openresty/share/GeoIP/GeoLite2-City.mmdb

test -s "$NEW_MMDB"
sha256sum "$NEW_MMDB"
mmdblookup --file "$NEW_MMDB" --ip 8.8.8.8 country iso_code
cp -a "$ACTIVE_MMDB" "${ACTIVE_MMDB}.manual.bak.$(date +%Y%m%d%H%M%S)"
install -o webuser -g users -m 0644 "$NEW_MMDB" "$ACTIVE_MMDB"
/opt/openresty/nginx/sbin/nginx -t
/opt/openresty/nginx/sbin/nginx -s reload
```

> 必须先完成第三章的旧数据基线创建，再替换 Master 当前 MMDB，这样才有可发布的回滚版本。

### 2. 创建新数据版本

1. 回到发布中心，点击“创建 GeoIP 版本”。
2. 说明填写数据来源和日期，例如：`2026-08 GeoLite2 City`。
3. 确认新版本 SHA-256 与以下命令一致：

```bash
sha256sum /opt/openresty/share/GeoIP/GeoLite2-City.mmdb
```

### 3. 灰度发布到 108.69

1. 在“GeoIP 数据”页找到新版本。
2. 点击“发布”。
3. 只选择 `10.15.108.69`。
4. 确认发布。
5. 在“GeoIP 任务”页等待状态变成“成功”。

Node 领取任务期间可执行：

```bash
watch -n 2 'cat /opt/openresty/zhongkui-waf/conf/.cluster/geoip-update-status.json 2>/dev/null || echo waiting'
```

任务可能依次显示：

```text
queued -> downloading -> validating -> switching -> success
```

按 `Ctrl+C` 退出观察。

Master 执行：

```bash
sha256sum /opt/openresty/share/GeoIP/GeoLite2-City.mmdb

Node 执行：

sha256sum /opt/openresty/share/GeoIP/GeoLite2-City.mmdb

  --ip 8.8.8.8 country iso_code

```

预期结果：

- Master 与 Node SHA-256 完全相同。
- Node 固定 IP 查询成功。
- Nginx 配置检查成功。

### 2. 查看更新服务

Node 执行：

```bash
systemctl status zhongkui-node-updater.timer --no-pager
systemctl status zhongkui-node-updater.service --no-pager
journalctl -u zhongkui-node-updater.service --since '30 minutes ago' --no-pager
```

### 3. 查看最新 WAF 错误

Master 和 Node 分别执行：

```bash
tail -n 300 /opt/openresty/nginx/logs/error.log | \
  grep -E '\[error\]|geoip|mmdb|program.update' | tail -n 50
```

没有输出，或者只有测试前的历史报错，即表示正常。

## 六、回滚验证

### 1. Node GeoIP 回滚

GeoIP 发布中心的回滚方式是“重新发布旧版本”：

1. 在“GeoIP 数据”页找到第三章创建的旧基线版本。
2. 点击“发布”。
3. 选择 `10.15.108.69`。
4. 等待“GeoIP 任务”状态变成“成功”。
5. 再次对比 Node SHA-256，应恢复成旧基线校验值。

### 2. Master GeoIP 回滚

发布中心不会自动替换 Master 自身。需要回滚 Master 时执行：

```bash
OLD_VERSION='旧GeoIP数据版本'
OLD_FILE="/opt/openresty/zhongkui-geoip-releases/$OLD_VERSION/GeoLite2-City.mmdb"
ACTIVE_FILE=/opt/openresty/share/GeoIP/GeoLite2-City.mmdb

(cd "/opt/openresty/zhongkui-geoip-releases/$OLD_VERSION" && sha256sum -c SHA256SUMS)
mmdblookup --file "$OLD_FILE" --ip 8.8.8.8 country iso_code
install -o webuser -g users -m 0644 "$OLD_FILE" "$ACTIVE_FILE"
/opt/openresty/nginx/sbin/nginx -t
/opt/openresty/nginx/sbin/nginx -s reload
```

### 3. 程序版本回滚

程序回滚同样通过发布旧版本完成：

1. 发布中心进入“程序版本”。
2. 找到已经保留的 `2.1.4` 快照。
3. 点击“发布”，选择需要回滚的 Node。
4. 在“程序任务”中确认任务成功。

## 七、验收标准

以下项目全部满足即可通过验收：

- Master 和 Node 程序版本均为 `2.1.5`。
- 2.1.5 程序快照能正常创建且包含 GeoIP 更新文件。
- GeoIP 基线和新数据版本均可创建，历史版本不会被覆盖。
- Node 能完成下载、校验、切换和状态上报。
- Master 与 Node MMDB SHA-256 一致。
- 固定公网 IP 查询正常。
- Nginx 配置检查和重载正常。
- 发布任务页面最终状态为“成功”。
- 重新发布旧 GeoIP 版本能够完成回滚。
- 更新过程不修改 `system.json`、规则、证书和日志。
